# 🚀 ✅ Use Case
When a **High-Value Lead (Rating = Hot)** is created:
✅ Publish Platform Event\
✅ Create Task for Sales team (Subscriber - Apex)\
✅ Show real-time notification in UI (Subscriber - LWC)
***
# ✅ ✅ Step 1: Create Platform Event
**Setup → Platform Events → New**
    * Label: **High Value Lead Event**
    * API Name: `High_Value_Lead__e`
    * Publish: **Immediately**
***
## ➕ Add Fields
* `Lead_Id__c` (Text 18)
* `Name__c` (Text)
* `Company__c` (Text)
* `Rating__c` (Text)
***

# ✅ ✅ Step 2: Trigger (Publisher on Lead)
```apex
trigger LeadTrigger on Lead (after insert) {

    List<High_Value_Lead__e> events = new List<High_Value_Lead__e>();

    for (Lead l : Trigger.new) {

        if (l.Rating == 'Hot') {

            events.add(new High_Value_Lead__e(
                Lead_Id__c = l.Id,
                Name__c = l.Name,
                Company__c = l.Company,
                Rating__c = l.Rating
            ));
        }
    }

    if (!events.isEmpty()) {
        EventBus.publish(events);
    }
}
```
✅ Publishes event when **Hot Lead created**
***
# ✅ ✅ Step 3: Apex Subscriber (Create Task)
            ```apex
            trigger LeadEventSubscriber on High_Value_Lead__e (after insert) {

                List<Task> taskList = new List<Task>();
                for (High_Value_Lead__e evt : Trigger.new) {
                    taskList.add(new Task(
                        Subject = 'Follow up with High Value Lead',
                        Description = 'Lead Name: ' + evt.Name__c,
                        Priority = 'High',
                        Status = 'Not Started'
                    ));
                }
                insert taskList;
            }
            ```
    ✅ Automatically creates **Task**
    ***
# ✅ ✅ Step 4: LWC Subscriber (Real-Time UI)
        ***
        ## 🔹 leadEventListener.js
        ```javascript
        import { LightningElement } from 'lwc';
        import { subscribe } from 'lightning/empApi';

        export default class LeadEventListener extends LightningElement {

            channelName = '/event/High_Value_Lead__e';
            subscription = null;

            connectedCallback() {
                this.subscribeToEvent();
            }

            subscribeToEvent() {
                subscribe(this.channelName, -1, (event) => {

                    const payload = event.data.payload;

                    console.log('Event received:', payload);

                    alert(
                        '🔥 New High Value Lead!\n' +
                        'Name: ' + payload.Name__c +
                        '\nCompany: ' + payload.Company__c
                    );

                }).then(response => {
                    this.subscription = response;
                    console.log('Subscribed successfully');
                });
            }
        }
        ```
