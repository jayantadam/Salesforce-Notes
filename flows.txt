IMP - In LWC we can call only screen flow but not autolaunched flow.
example - we have a screen flow which has a screen and then it calls an autolaunched flow to do some processing. In this case, we can call the screen flow from LWC, but we cannot directly call the autolaunched flow from LWC.


<template>
    <lightning-card title="Call Screen Flow">
        <lightning-button 
            label="Start Flow" 
            onclick={handleStart}>
        </lightning-button>

        <lightning-flow 
            onstatuschange={handleStatusChange}>
        </lightning-flow>
        <p if:true={flowResult}>
            Result: {flowResult}
        </p>
    </lightning-card>
</template>


import { LightningElement } from 'lwc';
export default class FlowCaller extends LightningElement {
    flowResult;
    handleStart() {
        const flow = this.template.querySelector('lightning-flow');
        const inputVariables = [
            {
                name: 'recordId',
                type: 'String',
                value: '001XXXXXXXXXXXX'
            }
        ];
        flow.startFlow('My_Screen_Flow', inputVariables);
    }

    handleStatusChange(event) {
        if (event.detail.status === 'FINISHED') {
            const outputVars = event.detail.outputVariables;
            outputVars.forEach(item => {
                if (item.name === 'resultMessage') {
                    this.flowResult = item.value;
                }
            });
            console.log('Flow finished');
        }
    }
}

3️⃣ Scheduled-Triggered Flow
What it does:
    Runs at a specific time/date
    Can run daily, weekly, or once
Used for:
    Reminder emails
    Data cleanup
    Mass updates

5️⃣ Platform Event-Triggered Flow
What it does:
  Runs when a Platform Event is received
Used for:
    Integrations
    Real-time system updates     

4️⃣ Autolaunched Flow (No Trigger)
What it does:
    Runs automatically
    No screens
    No trigger by itself
Triggered by:
        Apex
        Another Flow (Subflow)
        Process Builder (legacy)
        API
