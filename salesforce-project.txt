👉 A Lead = A person who might become a customer

type of leads:
1. Manual Leads: Created by sales reps or admins when they get a new inquiry via phone, email, or web forms.
2. Web-to-Lead: A Salesforce feature that allows you to capture leads directly from your website and automatically create Lead records in Salesforce.
3. Imported Leads: Imported from external lead generation services or CRM systems using tools like Data Loader or third-party integrations.
4. Social Media Leads: Captured from social media platforms using integrations or manual entry when customers express interest through social channels.
5. Automated Leads: Created automatically when a customer fills out a contact form on the website, or when marketing uploads a list of potential customers.
6. Campaign Leads: Generated from marketing campaigns, such as email blasts or events, and imported via data integration tools into Salesforce.
7. Trade Show Leads: Collected during trade shows or events, often entered manually by sales reps after the event.

Lead conversion is the process of converting a potential customer (Lead) into an Account, Contact, and Opportunity after qualification.

The Standard "Description" FieldSalesforce includes a standard, native box called Description on every Lead record.How it helps: It allows the person creating the lead (or a web form) to type out the specific notes, background context, or pain points.Where to find it: Usually located in the lower sections of the Lead details page layout.

2. Custom "Product Interest" PicklistAs mentioned previously, you can create a custom dropdown field specifically for tracking the purpose of the inquiry.How it helps: You can name this field Product Interest or Primary Pain Point.Example values: "Needs Software Upgrade", "Looking for Cloud Security", "Inquiring about Pricing".

3. "Lead Source" ContextWhile Lead Source only tracks where they came from (e.g., Trade Show, Website), you can make it highly specific to give you the "why".Example: If the Lead Source is set to "Webinar: 2026 AI Trends", you instantly know the lead was created because the customer wants to learn about or buy Artificial Intelligence solutions.

4. Automated Hidden Web Fields (Web-to-Lead)If the lead is automatically created when a customer fills out a contact form on your website:How it helps: You can map the "Message" or "Questions" text box from your website directly into the Salesforce Description field.Result: When you open the new lead, you will read exactly what the customer typed on your website.

5. Validation Rules (Forcing Reps to Provide a Reason)If your internal sales reps are creating leads manually and forgetting to input the reason, a Salesforce Administrator can set up a Validation Rule.How it helps: It blocks the rep from saving the Lead record unless they fill out the Description 
or Product Interest field, ensuring the "why" is always recorded.

Lead Assignment Rule ->
setup > lead assignment rules > new rule > rule entries (criteria + user/queue assignment)

Rule 2 : Assign Leads to the queue if country = USA and product interest = Marketing Tool email template: "New Lead Assigned - Marketing Tool"


Duplicate Rule ->
lead object -> setup > duplicate rules > new rule > select object (Lead) > define matching criteria (e.g., email) > select action (block or allow with alert) > activate
- this prevents creating duplicate leads based on defined criteria (e.g., same email address)
Example:
Rule 1 : Block duplicate leads if email = neha@brighttech.com

----------------------------------------------stage and probablity in custom object----------------------------------------------------------------------------------
### 1. Stage Field in a Custom Object
      You can create a custom field such as:
      * **Field Type:** Picklist
      * **Example Values:** Prospecting, Qualification, Proposal, Negotiation, Closed Won, Closed Lost
      This behaves like an Opportunity Stage field but is fully custom.
      Example:
      * API Name: `Stage__c`
      * Type: Picklist
---
### 2. Probability Field in a Custom Object
        You can create:
        * **Field Type:** Percent
        * API Name: `Probability__c`
        Example values:
        * 10%
        * 40%
        * 75%
        * 100%
---
### 3. Auto-Update Probability Based on Stage (Optional)
          Unlike the standard Opportunity object, Salesforce does **not automatically map Stage → Probability** in custom objects.
          To automate it, you can use:
              * **Record-Triggered Flow** (recommended)
              * Validation Rules
              * Apex Trigger (advanced)
              Example logic:
              | Stage         | Probability |
              | ------------- | ----------- |
              | Prospecting   | 10%         |
              | Qualification | 30%         |
              | Proposal      | 60%         |
              | Negotiation   | 80%         |
              | Closed Won    | 100%        |
              | Closed Lost   | 0%          |
              A Flow can automatically populate `Probability__c` when `Stage__c` changes.
    ---
  ### 4. Similarity to Opportunity Features
          Custom objects can mimic Opportunities, but they won’t automatically get:
          * Sales Path
          * Forecasting
          * Opportunity pipeline features
          * Built-in probability calculations
          Unless you configure those separately.
---
### Recommended Setup
      For most implementations:
      | Field               | Type         |
      | ------------------- | ------------ |
      | Stage__c            | Picklist     |
      | Probability__c      | Percent(3,0) |
      | Amount__c           | Currency     |
      | Expected_Revenue__c | Formula      |
      Expected Revenue formula:

```text
Amount__c * Probability__c
```
---
### Formula Example
You can even calculate probability dynamically:
          ```text
          CASE(
          Stage__c,
          "Prospecting", 10,
          "Qualification", 30,
          "Proposal", 60,
          "Negotiation", 80,
          "Closed Won", 100,
          0
          )
```
