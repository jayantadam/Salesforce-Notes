## 1) Opportunity “Closed Won” → Create Project\_\_c (Idempotent)

**Story**  
When an Opportunity’s `StageName` changes to “Closed Won”, create a `Project__c` (lookup to Opportunity)
and set `Project_Manager__c = Opportunity.OwnerId`. Prevent duplicates if the record is edited multiple times.

**Constraints & Tests**
*   Bulk updates (≥200 Opportunities).
*   Only when stage **changes** to Won (delta check).
*   Don’t create a second Project if one already exists.
*   After Update context (need Opp Id).

**What’s being tested**  
Delta detection, idempotency, bulkification, single query + single DML.

**Hints / Gotchas**

*   Collect Won Opp Ids with an old→new stage check.
*   Query existing Projects in one SOQL.
*   Insert only missing Projects.

**Skeleton**

```apex
trigger OpportunityTrigger on Opportunity (after update) {
    Set<Id> wonIds = new Set<Id>();
    for (Opportunity o : Trigger.new) {
        Opportunity oldO = Trigger.oldMap.get(o.Id);
        if (o.StageName == 'Closed Won' && oldO.StageName != 'Closed Won') wonIds.add(o.Id);
    }
    if (wonIds.isEmpty()) return;

    Set<Id> alreadyHasProject = new Set<Id>();

    for (Project__c p : [SELECT Opportunity__c FROM Project__c WHERE Opportunity__c IN :wonIds]) {
        alreadyHasProject.add(p.Opportunity__c);
    }

    List<Project__c> toInsert = new List<Project__c>();
    for (Opportunity o : [SELECT Id, OwnerId FROM Opportunity WHERE Id IN :wonIds]) {
        if (!alreadyHasProject.contains(o.Id)) {
            toInsert.add(new Project__c(Opportunity__c = o.Id, Project_Manager__c = o.OwnerId));
        }
    }
    if (!toInsert.isEmpty()) insert toInsert;
}

## 2) Lookup Rollup: Quote\_\_c → Opportunity (Sum Net\_Amount\_\_c)

**Story**  
Keep `Opportunity.Amount` equal to the sum of related `Quote__c.Net_Amount__c` via Lookup (not Master‑Detail).

**Constraints & Tests**

*   Trigger on Quote\_\_c for **insert/update/delete/undelete**.
*   Bulk safe, default Opportunity.Amount to 0 if no Quotes.
*   No recursion if other automation touches `Amount`.

**Skeleton (core aggregation loop)**

```apex

Set<Id> oppIds = new Set<Id>();
for (Quote__c q : Trigger.new) oppIds.add(q.Opportunity__c);
for (Quote__c q : Trigger.old) oppIds.add(q.Opportunity__c);

Map<Id, Decimal> sumByOpp = new Map<Id, Decimal>();

for (AggregateResult ar : [
    SELECT Opportunity__c opp, SUM(Net_Amount__c) total
    FROM Quote__c
    WHERE Opportunity__c IN :oppIds
    GROUP BY Opportunity__c
]){
    sumByOpp.put((Id) ar.get('opp'), (Decimal) ar.get('total'));
}

List<Opportunity> ups = new List<Opportunity>();
for (Id oppId : oppIds) {
    ups.add(new Opportunity(Id=oppId, Amount = sumByOpp.containsKey(oppId) ? sumByOpp.get(oppId) : 0));
}
update ups;
```

## 3) Prevent Account Owner Change if Open Opportunities Exist

**Story**  
Disallow changing `Account.OwnerId` if the Account has **any** open Opportunities.

**Constraints & Tests**

*   **Before update** on Account.
*   Bulk owner transfers; precise and selective SOQL.
*   User‑friendly error on `OwnerId` field.

**What’s being tested**  
Validation via `addError`, selective queries, bulk logic.

**Hints / Gotchas**

*   Only check records where `OwnerId` actually changed.
*   One SOQL using `IN :accountIds` and filter `IsClosed = false`.

**Skeleton**

```apex
trigger AccountTrigger on Account (before update) {
    Set<Id> toCheck = new Set<Id>();
    for (Account a : Trigger.new) {
        Account oldA = Trigger.oldMap.get(a.Id);
        if (a.OwnerId != oldA.OwnerId) toCheck.add(a.Id);
    }
    if (toCheck.isEmpty()) return;

    Set<Id> blocked = new Set<Id>();
    for (AggregateResult ar : [
        SELECT AccountId a, COUNT(Id) c
        FROM Opportunity
        WHERE AccountId IN :toCheck AND IsClosed = false
        GROUP BY AccountId
    ]) {
        if (((Integer)ar.get('c')) > 0) blocked.add((Id)ar.get('a'));
    }

    for (Account a : Trigger.new) {
        if (blocked.contains(a.Id)) a.OwnerId.addError('Owner cannot be changed while open Opportunities exist.');
    }
}
```
