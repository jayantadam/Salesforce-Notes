1. What is SOQL?
Answer: SOQL (Salesforce Object Query Language) is Salesforce’s query language used to retrieve data
stored in Salesforce objects (standard and custom). It is similar to SQL SELECT but tailored for
Salesforce’s data model. You cannot use DDL or DML with SOQL; it only reads data.
        ✔️ Summary
        SOQL = SELECT only
        DML = Apex (insert/update/delete/undelete/upsert)
        DDL = Metadata or Tooling API
  Example: Example: SELECT Id, Name FROM Account WHERE Name LIKE 'A%',

 What is a parent-to-child relationship query?
    Answer: A query from a parent record pulling a set of its child records using a subquery on the child relationship name.
    Example: SELECT Id, Name, (SELECT Id, Title FROM Contacts) FROM Account WHERE Name LIKE 'T%'
             ⛔ Subqueries cannot be nested (no children-of-children in one query).

 What is a child-to-parent relationship query?
    Answer: A query from child records referencing fields on the parent using dot notation.
    Example: Example: SELECT Id, Title, Account.Name, Account.Industry FROM Contact WHERE Account.BillingCountry = 'India'
              You can traverse up to 5 levels.

   -- Multi-level (grandparent, etc.)

 How is SOQL different from SQL?
Answer: SOQL supports only SELECT-like operations, no INSERT/UPDATE/DELETE, and does not
support traditional joins. Instead, it uses relationship queries (parent-to-child subqueries and
child-to-parent dot notation).
  Example: Example: Child-to-parent
  : SELECT LastName, Account.Name FROM Contact,
  : SELECT Title, AccountId, Account.Name, Account.Id FROM Contact WHERE AccountId = '0015g00000ABCdEAA1'               
  : SELECT Title, AccountId, Account.Name, Account.Id FROM Contact WHERE AccountId IN ('0015g00000ABCdEAA1', '0015g00000XYZwQAA1')
  : SELECT Title, AccountId, Account.Name, Account.Id FROM Contact WHERE Account.Name LIKE 'Acme%

 How do you filter results
        Answer: Use WHERE with operators like =, !=, <, >, <=, >=, LIKE, IN, NOT IN, AND, OR, and parentheses. 
        Example: Example: SELECT Id, Name FROM Account WHERE Industry = 'Technology' AND BillingCountry = 'India'

How do you sort and limit rows?
    Answer: Use ORDER BY for sorting and LIMIT for restricting the number of rows. OFFSET can be used for pagination.
    Example: Example: SELECT Id, Name FROM Account ORDER BY CreatedDate DESC LIMIT 10 OFFSET 10

How do you query NULL and NOT NULL?
    Answer: Use = null and != null in WHERE clause.
    Example: Example: SELECT Id, Name FROM Account WHERE Phone = null

 What is a semi-join?
    Answer: Filtering records using IN with a subquery.
    Example: Example: SELECT Id, Name FROM Account WHERE Id IN (SELECT AccountId FROM Contact)
========================================================================================================================================================================================================================================
What is an anti-join?
    Answer: Filtering records using NOT IN with a subquery.
    Example: Example: SELECT Id, Name FROM Account WHERE Id NOT IN (SELECT AccountId FROM Contact)

 How do you use aggregate functions?
    Answer: Use COUNT, SUM, AVG, MIN, MAX with GROUP BY to aggregate data.
    Example: Example: SELECT Industry, COUNT(Id) FROM Account GROUP BY Industry HAVING COUNT(Id) > 5

What is the difference between COUNT() and COUNT(Field)?
    Answer: COUNT() returns total rows; COUNT(Field) counts only rows where that field is non-null.
    Example: Example: SELECT COUNT() FROM Lead; SELECT COUNT(Phone) FROM Lead

15. How do you lock rows during a transaction?
        Key points
        The lock is exclusive and held until the transaction ends (commit/rollback).
        FOR UPDATE is only supported in Apex (not via API tools like Data Loader).
        Use FOR UPDATE in the same transaction where you do the DML that needs protection.

example 1.  Set<Id> parentIds = new Set<Id>();
                for (Account a : childAccts) {
                    if (a.ParentId != null) parentIds.add(a.ParentId);
                }

                List <Account> accts = [
                    SELECT Id, Name
                    FROM Account
                    WHERE Id IN :parentIds
                    FOR UPDATE
                ];

                // Safe to perform related DML on these accounts or their children
                for (Account a : accts) {
                    a.Name = a.Name + ' (Locked & Updated)';
                }

                update accts; // lock is held until the transaction completes

What Are Polymorphic Fields in Salesforce?
A polymorphic field is a special Salesforce lookup field that can reference more than one object type.
    In other words:
    Instead of pointing to a single fixed object (like Account or Contact),
    it can point to different parent objects depending on the record.
    
    OwnerId Who owns the recordUser OR Queue
    WhatId (on Task/Event)The non‑person objectAccount, Opportunity, Case, Campaign, Any custom object (__c), etc.
    WhoId (on Task/Event)The person objectContact OR Lead

   Example: SELECT Id, WhoId, WhatId, Subject FROM Task
========================================================================================================================================================================================================================================
What is TYPEOF in SOQL?
TYPEOF in SOQL is a conditional, polymorphic query construct that allows you to retrieve different fields based on the actual object type
referenced by a polymorphic lookup field (such as WhoId, WhatId, OwnerId, etc.).

        SELECT 
            Id,
            Subject,
            TYPEOF What
                WHEN Account THEN Name, Industry
                WHEN Opportunity THEN Name, StageName
                WHEN Case THEN CaseNumber, Status
                ELSE Id
            END
        FROM Task

How do you query big objects?
  Answer: Big objects use Async SOQL or SOQL with restrictions; typically queried via Analytics/Async SOQL.
  Example: Async SOQL job targeting Big Object data
    
{
  "query": "SELECT Account__c, COUNT(Id) FROM CustomerEvents__b GROUP BY Account__c",
  "targetObject": "AccountSummary__c",
  "operation": "insert"
}This query: Runs asynchronously
Reads from the Big Object CustomerEvents__b
Writes grouped results into the AccountSummary__c object
✔ Async SOQL only supports:
    SELECT, FROM
    WHERE (with index fields only)
    GROUP BY
    ORDER BY (with limits)
    Aggregation functions (COUNT, etc.)

❌ Unsupported:
    JOINs
    Subqueries
    OFFSET
    LIMIT with non-index ordering
    Filtering on non-index fields

How do you get recently viewed or referenced records?
    Answer: Use FOR VIEW or FOR REFERENCE to update view/reference tracking. To query “recent items”

How do you query tasks and events (activities)?
Answer: Query Task and Event separately, or use ActivityHistory (read-only) for combined history in

How do you query for orphan child records?
Answer: Filter where the lookup field is null.
Example: SELECT Id, LastName FROM Contact WHERE AccountId = null

Can you use HAVING without GROUP BY?
Answer: No. HAVING must follow a GROUP BY with an aggregate function.
    Example: Example: SELECT StageName, COUNT(Id) FROM Opportunity GROUP BY StageName
    HAVING COUNT(Id) > 3

Can you create alias fields or tables?
    Answer: SOQL does not support table aliases like SQL. Field aliasing is available only in aggregation
    contexts for API responses, not Apex.
    Example: Example: SELECT COUNT(Id) cnt FROM Account GROUP BY Industry (API naming)
